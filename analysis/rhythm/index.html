Rhythmic Patterns

Counting rules

Each occurrence is one voice in one notated measure. The active *met sign determines its mensuration category; the active time signature determines expected measure length. Different mensurations and measure lengths remain separate. This admits triple measures, rather than limiting everything to 8 or 16 quarter notes. It does not yet reconstruct an independent breve/long grid for unusual editorial barring or proportions.

Rests inside a pattern are retained. When crossing notes are included, durations are clipped to the measure; incoming continuations have a t prefix and outgoing continuations a ~ suffix in the pattern code. The notation shows the segment’s duration; continuation information is in the code below it. The note extractor merges ties, so internal written ties are not distinguished from an equivalent sustained note.

Pattern codes use b = breve, w = whole, m = half, q = quarter, e = eighth; d = dot and r = rest. Percentages use the number of included voice-measures in the same mensuration and measure-length group, after applying the selected rules. Overlapping events and mid-measure meter changes are held for review.

Sources: Craig’s menpat examples and JRP analysis help. Mensuration images follow the VHV mensural-signs reference. Occurrence links open the work; the listed measure and voice identify the passage.
