# Mensuration signs

These 22 SVG images use the original outlines from the illustrations in the
[Mensural signs table in the VHV documentation](https://doc.verovio.humdrum.org/humdrum/mens/#mensural-signs),
authored by Craig Stuart Sapp. Only the outer canvas is trimmed and given a viewBox for scalable display;
the glyph paths are unchanged. They are served locally by the JRP website.

The exact Humdrum-code mapping is stored in
`_includes/metadata/mensuration-signs.json`. Codes absent from that reference
table retain their text labels; no equivalence is inferred.
