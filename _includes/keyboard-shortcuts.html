Keyboard Shortcuts

Various pages on the JRP website have keyboard shortcuts. The lists below show the available shortcuts for each page type.

Repertoire page

Shift+→
View next page of the repertoire list.
Shift+←
View previous page of the repertoire list.
Ctrl+−
Decrease the number of lines in the repertoire table.
Ctrl+=
Increase the number of lines in the repertoire table.
Ctrl+A
Toggle display of repertoire table between paged and unpaged views.
Ctrl+J
Toggle display of catalog number/genre in first column of repertoire table.
Ctrl+N
Show/hide number of works in the repertoire list. The work count is shown underneath the repertoire filters.

Work page

Shift+→
Go to next work page.
Shift+←
Go to previous work page.
Ctrl+Shift+→
Go to first work in next repertory.
Ctrl+Shift+←
Go to first work in previous repertory.
Shift+Home
Go to first work in first repertory.
Shift+End
Go to last work in last repertory.
Shift+↑
Go to previous section in a multi-section work.
Shift+↓
Go to next section in a multi-section work.
1 — 9 / Ctrl+1 — 9
Display specified section number. Control-number will work with any focus.
I / Ctrl+I
Toggle view of all incipits for multi-section works. I-key will work when not in an input box. Control-I will work with any focus.
P / Ctrl+P
Play audio for currently selected section (or work for single-sectioned work). P-key will work when not in an input box. Control-P will work with any focus.
R / Ctrl+R
Toggle view of all vocal ranges for multi-section works. R-key will work when not in an input box. Control-R will work with any focus.
D / Ctrl+D
Toggle range type view (histograms by note counts or duration weighted). D-key will work when not in an input box. Control-D will work with any focus.
