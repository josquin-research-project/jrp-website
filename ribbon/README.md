# Ribbon analysis interface

Adapted from the preserved craigsapp/ribbon interface:
https://github.com/craigsapp/ribbon

D3 3.5.6, ColorBrewer, and queue are preserved upstream dependencies. The
interactive rendering is kept together in index.html to preserve the approved
prototype. Data is generated by digital-library-build from the published R2
Humdrum master; no Stanford service is called.
